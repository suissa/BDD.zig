# Differential operator verification

The operator model is exported by Zig itself. CI serializes all 7 × 7 × 15 = 735 primitive/operator combinations to `tests/generated-operator-matrix.json`, then Node executes each pair against the JavaScript runtime.

For every generated operator case, the reference test checks the modeled result category or verifies a modeled `TypeError`.

Concrete value cases now have a single source of truth: `src/semantic_cases.zig`. The exporter `src/export_semantic_cases.zig` serializes those typed cases and expected values/errors to `tests/generated-semantic-cases.json`. The Node suite reads that generated manifest; the 29 scenarios are no longer duplicated in JavaScript. The exporter includes the classifier's predicted result category and outcome for each case, and the reference suite checks those predictions against the runtime's actual type, operand selection, and TypeError behavior. Partition names are resolved to concrete JavaScript values at execution time, and successful results are compared using `Object.is`, including a dedicated `NaN` check. Expected errors are checked by class.

Coverage includes numeric/invalid/empty strings, null and undefined coercion, zero and negative zero, NaN, infinity, BigInt division/remainder by zero, negative BigInt exponent, mixed BigInt/Number errors, Symbol conversion, logical operand selection, bitwise conversion, Boolean-to-Number coercion, lexical string comparison, and strict/loose equality (including null/undefined and BigInt type preservation).

This is focused differential regression coverage, not exhaustive ECMAScript conformance.

Run locally:
1. `zig build test`
2. `zig run src/export_operator_matrix.zig`
3. `node --test tests/operator-reference.test.mjs`
4. `zig run src/export_semantic_cases.zig`
5. `node --test tests/concrete-semantic-reference.test.mjs`


## Reproducing a divergence

Each divergence report entry now carries the classifier rule rationale, a stable `caseId`, the exact value-partition indexes, the runtime-observed value/error, and a minimal JavaScript expression. The Zig matrix exporter includes the rule rationale so the report points to the semantic assumption under test.

Replay a report generated by a failed partition test with:

```sh
node tests/replay-semantic-divergences.mjs
# Or specify a saved report:
node tests/replay-semantic-divergences.mjs /path/to/semantic-divergences.json
```

The replay tool resolves the original operand partitions, executes each operator again, and verifies that the runtime outcome matches the recorded observation. This confirms the case is reproducible; the original differential test remains responsible for detecting the classifier mismatch.
